# Hotel Booking & Revenue Analysis

## Project Overview

This project focuses on analyzing hotel booking data to identify booking patterns, customer behavior, revenue-related trends, and other useful business insights.

The project combines Exploratory Data Analysis using Python and SQL-based data analysis.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL

## Project Components

### 1. Exploratory Data Analysis

Performed data exploration and analysis using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

The analysis includes:

- Understanding the structure and characteristics of the dataset
- Checking data types and missing values
- Data cleaning and preprocessing
- Identifying and handling duplicate records
- Analyzing booking patterns
- Exploring numerical and categorical variables
- Grouping and aggregating data
- Creating visualizations to identify trends and patterns

### 2. SQL Analysis

Used MySQL to perform data analysis through SQL queries.

The SQL analysis includes:

- Filtering and sorting data
- Aggregate functions
- GROUP BY and HAVING
- JOIN operations
- Subqueries
- Conditional analysis
- Revenue and booking-related analysis
- Extracting meaningful insights from the dataset

## Key Skills Demonstrated

- Data Cleaning
- Exploratory Data Analysis
- SQL Querying
- Data Visualization
- Data Aggregation
- Business Insight Generation
- Analytical Thinking

## Project Files

- `hotel_booking.ipynb` – Python-based Exploratory Data Analysis
- `hotel_booking_analysis.sql` – SQL queries and analysis
